Création d'évaluation

Cette page explique le fonctionnement du système d'importation d'évaluations sur le site GazePlay-Eval. Il y a deux façons possibles de visualiser une évaluation importée : en mode consultation ou en mode sauvegarde.

Pour que le site puisse importer l'évaluation, celle-ci doit obligatoirement être au format .gpSave , obtenu après qu'une évaluation ait été entièrement créée.
Mode Consultation

Le mode Consultation permet de charger une évaluation sans la sauvegarder. Cette option peut être pratique si vous souhaitez visualiser le contenu d'une évaluation mais que vous ne souhaitez pas la conserver ou que vous n'avez plus de place disponible.

L'évaluation chargée en mode Consultation sera perdue si vous quittez le site ou rechargez la page. Pensez bien à la sauvegarder si vous souhaitez conserver vos modifications !
Mode Sauvegarde

Le mode Sauvegarde permet de placer l'évaluation importée dans un des 3 emplacements disponibles sur le site. Il est donc possible de la consulter dans l'immédiat, de revenir dessus plus tard ou de la modifier tout en conservant les changements apportés.

Ce mode nécessite d'un d'avoir au moins un emplacement vide où mettre l'évaluation importée. S'il n'y a pas d'emplacements disponibles, il sera nécessaire de supprimer l'évaluation d'un emplacement existant.
